# Featured project covers

This folder contains the four large project covers used in the website's featured-project cards.

- Keep each file at **1200 × 675 px (16:9)**, with the full illustration kept inside the frame.
- Replace a cover here and keep its filename to update the matching card without changing the card layout.
- Use `sahm-ai.svg`, `content-agent.svg`, `financial-docs.svg`, and `assembly-line.svg` for the current featured set.
- Each matching project card links to its source repository; the cover itself should remain an accurate visual of that project.
